What this is

    

      Bioconductor packages built for WebAssembly, installed straight into the
      browser from
      webr.bioconductor.org, with
      CRAN dependencies from repo.r-wasm.org.
      The same thing works inside a package vignette — see
      the webR documentation.
    


    
What it costs you

    
    
      
  • The first load downloads R itself — tens of megabytes, then cached.
    • 
      
  • Packages install per session, a few seconds each. Nothing persists across a reload.
    • 
    


    
Where it stops

    
    
      
  • A browser tab: limited memory, no parallelism, no real filesystem.
    • 
      
  • Anything needing threads, sockets or subprocesses may install and still fail at runtime.
    • 
      
  • Built for small, self-contained examples — not for an analysis.
    •
